# AITU Market Bot

Telegram-бот барахолки AITU: собирает объявления от студентов, отправляет их
на модерацию администраторам и публикует одобренные посты в канал.

Стек: Python 3.10+, aiogram 3, SQLite (aiosqlite).

## Возможности

**Пользователь**
- `/start` — приветствие и меню: `📢 Подать объявление`, `📜 Правила канала`.
- Подача в 4 шага (FSM): категория → текст (до 800 символов) → фото
  (одно или альбом до 4 шт., можно пропустить) → контакт.
  Контакт берётся из `@username` автоматически; если юзернейма нет — бот просит
  написать контакт текстом.
- В конце бот показывает превью поста и сообщает, что объявление ушло на модерацию.
- Отменить подачу можно кнопкой `❌ Отменить подачу` или `/cancel`.

**Администратор**
- Получает карточку `НОВОЕ ОБЪЯВЛЕНИЕ #N` (автор, ID, категория, контакт, текст,
  фото) с кнопками `✅ Одобрить и опубликовать` / `❌ Отклонить`.
- Одобрение: пост с хэштегом категории уходит в канал, карточка блекнет
  (курсив) с отметкой «Одобрено админом @admin 🟢», автору приходит уведомление.
- Отклонение: карточка помечается «Отклонено 🔴», админ выбирает причину
  (`Спам`, `Не по теме`, `Запрещенка`), автору приходит уведомление с причиной.
  До выбора причины отклонение можно отменить.
- Если карточки разосланы нескольким админам, решение одного обновляет карточки
  у всех; повторное нажатие не приведёт к двойной публикации.
- Команды: `/admin` (справка), `/delete <ID объявления>` (удалить пост из канала),
  `/ban <ID>` / `/unban <ID>`, `/stats`. `/myid` показывает ваш ID и ID чата.

**Безопасность**
- Список админов задаётся в `.env` (`ADMIN_IDS`); нажатия на кнопки модерации
  от посторонних игнорируются.
- Анти-спам: не больше 1 объявления в 10 минут на пользователя
  (`RATE_LIMIT_SECONDS`, на админов не распространяется).
- Пользовательский текст экранируется — HTML-разметку внедрить нельзя.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Добавьте бота в канал (например, `@aitu_hub`) **администратором** с правами
   «Публикация сообщений» и «Удаление сообщений».
3. Узнайте ID админов: напишите боту `/myid` (или [@userinfobot](https://t.me/userinfobot)).
   Каждый админ должен хотя бы раз нажать `/start` у бота, иначе Telegram не даст
   боту написать ему первым.
4. Настройте окружение:

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env             # и заполните значения
   ```

5. Запустите:

   ```bash
   python -m bot
   ```

### Чат модераторов (необязательно)

По умолчанию карточки приходят каждому админу в личку бота. Чтобы получать их в
общий секретный чат: создайте группу, добавьте туда бота, отправьте в группе
`/myid` и пропишите полученный ID чата в `ADMIN_CHAT_ID`. Нажимать кнопки в
этом чате смогут только пользователи из `ADMIN_IDS`.

## Настройки (`.env`)

| Переменная           | Описание                                                     |
|----------------------|--------------------------------------------------------------|
| `BOT_TOKEN`          | Токен бота                                                   |
| `ADMIN_IDS`          | ID администраторов через запятую                             |
| `CHANNEL_ID`         | Канал для публикации: `@username` или `-100…`                |
| `ADMIN_CHAT_ID`      | ID чата модераторов (если пусто — личка каждого админа)      |
| `DB_PATH`            | Путь к файлу SQLite (по умолчанию `bot.db`)                  |
| `RATE_LIMIT_SECONDS` | Интервал между объявлениями пользователя (по умолчанию 600)  |

Тексты (приветствие, правила, сообщения) и список категорий/причин отказа
лежат в `bot/texts.py`.

## База данных

- `users` — ID, юзернейм, дата регистрации, статус (`active` / `banned`).
- `advertisements` — ID, автор, категория, текст, контакт, фото (file_id),
  статус (`new` / `approved` / `rejected` / `deleted`), причина отказа, модератор,
  ID опубликованного сообщения в канале (для удаления через `/delete`).
- `moderation_cards` — где лежат карточки объявления у модераторов
  (чтобы обновлять их у всех после решения).

Состояния анкеты (FSM) хранятся в памяти: при перезапуске бота незаконченная
подача сбрасывается, а все поданные объявления остаются в базе.

## Структура

```
bot/
  __main__.py      точка входа (python -m bot)
  config.py        загрузка .env
  db.py            SQLite: пользователи, объявления, карточки модерации
  texts.py         тексты, категории, форматирование постов и карточек
  keyboards.py     клавиатуры и callback-данные
  states.py        состояния FSM
  moderation.py    рассылка карточек, публикация, уведомления
  middlewares/     склейка альбомов (MediaGroup) в одно событие
  handlers/
    user.py        сценарий пользователя
    admin.py       модерация и команды админа
tests/             сценарные тесты с подменённым Telegram API
```
